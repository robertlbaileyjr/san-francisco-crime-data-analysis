# San Francisco Crime Data Analysis

## Project Overview
Analyzed 2018 San Francisco crime data to identify geographic, seasonal, and time-based crime trends.

## Business Objective
Identify recurring crime patterns and support operational resource allocation through data analysis and visualization.

## Tools Used
- Tableau
- Excel
- Pivot Tables

## Key Findings
- Crime rates peaked between 12 PM–8 PM and on weekends
- Theft-related crimes increased during summer months
- Mission, Tenderloin, and Southern districts showed highest crime concentration
- Specific intersections demonstrated recurring crime patterns

## Recommendations
- Increase patrol presence during peak periods
- Prioritize high-crime districts and intersections
- Adjust staffing based on seasonal and weekly trends
